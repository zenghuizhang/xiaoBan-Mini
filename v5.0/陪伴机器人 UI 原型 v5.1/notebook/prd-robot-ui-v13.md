# M5Stack CoreS3 Companion Robot UI v13
- Restored Child Theme ("温暖儿童") with milky yellow background (`#FFF9E6`) and coral orange glowing scheme (`#FF7F50`).
- Theme can be seamlessly switched in the HUD Menu (accessed via double-clicking the screen).
- Added a full-screen Boot Animation (`/?state=boot`) that adapts to the current theme:
  - Tech Theme: Hacker-style scanning line, loading bars and "SYSTEM BOOTING..." text.
  - Child Theme: Bouncy smiley face and "HELLO!" greeting.
- Default route now lands on the boot animation, which auto-transitions to idle after 3.5s.
- Maintained 320x240 resolution. UI Language: Chinese.
