# M5Stack CoreS3 Companion Robot UI v10
- Desktop Robot Redesign: Removed app-like navigation and status bar conventions to focus purely on the robot expression.
- Status Bar completely removed, maximizing the vertical space for the face.
- Face component scaled up (`baseScale` increased to 1.6) for a fuller, more immersive expression.
- Theme simplified: Removed the theme toggle. Strict adherence to the dark tone + cyan glowing style.
- Overlays (Menu & Wi-Fi Setup) redesigned into HUD-like centered translucent layers, abandoning typical mobile app top-bar navigation.
- Interaction: Maintained the double-click to show/hide the bottom menu bar.
- Resolution: 320x240, UI Language: Chinese.
