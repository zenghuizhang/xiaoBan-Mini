# M5Stack CoreS3 Companion Robot UI v12
- Redesigned the "Wink" (眨眼) expression to closely replicate the iconic, highly expressive wink of Athena Chu (朱茵) in A Chinese Odyssey.
- Changed the animation logic from a static squeezing loop to a dynamic, snappy full-action loop (Idle -> Sudden Wink & Wide Smile -> Hold -> Back to Idle).
- Left Eye (Winking): Squeezes tightly, shifts downwards, and tilts inward sharply.
- Right Eye (Open): Widens significantly, shifts upwards, and tilts slightly to mimic a head tilt.
- Mouth: Opens into a wide, sweet, asymmetrical smile (tilted and shifted to align with the active eye).
- Uses a 10-step array keyframe for a duration of 2.5 seconds to create a fast, spirited execution with a natural pause.
- Maintained 320x240 resolution, dark/cyan glowing theme, and minimalist no-eyebrow design.
- UI Language: Chinese.
