## 3. 新增功能(P0/P1)

### 3.1 AI 对话(P0)

**用户故事**:作为用户,我点 Sector 1(Message),进入对话页和机器人聊天;它会实时显示思考、回应文字,表情同步;我可以打断、复制、重发。

**关键能力**:
- 流式 SSE 响应(首 token < 1.2s P95);
- 上下文携带(电量/主题/位置/时间);
- 语音输入(Phase 2,本期 P1 仅文字 + 麦克风按钮占位);
- 错误恢复(重试/兜底话术);
- 表情联动(thinking/talking/happy_blink/sad)。

**非功能**:
- 首次开启「对话云端保留」前必须弹合规说明 modal;
- 默认仅 100% 元数据上报、1% 内容采样;
- 历史可一键清空。

### 3.2 Wi-Fi 配网(P0)

**用户故事**:开机首次或断网后,机器人自动进入配网页;我用手机连「MiraBot-XXXX」AP,自动弹出 Captive Portal 输 Wi-Fi 密码;3 分钟内完成。

**双方案**:
- AP + Captive(默认,无需 App);
- 6 位云码 + App(可选,体验更顺,Sprint 2 起灰度)。

### 3.3 OTA 升级(P0)

**用户故事**:有新版本时,屏幕推送提示卡片;我点「立即升级」看进度,完成后自动重启;失败自动回滚不变砖。

**通道**:stable / beta / dev,设置页可切;A/B 双分区,3 次启动失败自动回滚。

### 3.4 技能商店(P1)

**用户故事**:点 Sector 4(Puzzle)看已安装技能,可启停;商店浏览推荐技能,看权限后安装;在对话中说"番茄钟"机器人能直接执行。

**示例技能**(首批):
1. weather_today — 天气查询;
2. alarm — 闹钟/计时;
3. pomodoro — 番茄钟;
4. parrot — 鹦鹉学舌(语音);
5. translate — 翻译。

### 3.5 MCP 远端调用(P2)

**用户故事**:我在飞书 Mira 让它"切到开心表情",机器人立刻执行;此时屏顶显示 🔌 表示正被调用。

默认关;开启时屏顶常驻提示;ACL 白名单方式。

## 5. 关键 UX 流程图(文本版)

### 5.1 首次开机

```
[开机自检]
   │
   ├─ 检测到 NVS Wi-Fi 凭据 ─→ STA 重连 ─→ [主页]
   │
   └─ 无凭据/失败 3 次 ─→ [配网页]
                            │
                            ├─ AP+Captive 模式 ─→ 用户输 SSID/PWD
                            │     │
                            │     └─→ 切 STA ─→ 联网成功 ─→ [主页]
                            │
                            └─ 云配对模式 ─→ 显示 6 位码 ─→ App 输入并下发
                                  │
                                  └─→ 切 STA ─→ 联网成功 ─→ [主页]
```

### 5.2 对话主流程

```
[径向菜单 Sector 1] ─→ [对话页]
   │
   └─ 用户输入/语音 ─→ face=THINKING
        │
        └─ claw_core_send ─→ 后台 LLM Gateway (SSE)
              │
              ├─ 首 token: face=TALKING, UI 流式渲染
              ├─ tool_call: 端侧执行 → 续 turn
              └─ DONE: face=HAPPY_BLINK 0.8s → IDLE
```

### 5.3 OTA

```
[Settings 检查更新] / [后台推送]
   │
   └─→ /v1/ota/manifest ─→ 304 (无更新) / 200 卡片
         │
         └─→ 用户点「立即升级」
               │
               ├─ 下载(可断电续传)
               ├─ 校验 SHA-256 + 签名
               ├─ 写 ota_1
               ├─ 标记激活、重启
               │
               └─ 启动连续失败 3 次 → 回滚 ota_0
```

- 视频通话/视觉理解;
- 多设备群聊;
- 端侧 ASR/TTS(走云端,Phase 2 评估端侧轻量模型)。

## 1. 设计原则补丁

在 v6.1 三大原则(主题感、表情人格化、低门槛)基础上叠加:

4. **状态可见**:任何耗时/异步动作必须有 face + 顶栏 + 进度三层反馈;

#### 3.1.3 表情联动时序

```
t=0      用户点发送
         face: IDLE → THINKING(渐变 200ms,眨眼频率↑)
t=300ms  显示 Bot 思考占位(3 dot)
t=~1.2s  首 token 到达
         face: THINKING → TALKING(嘴部循环 400ms)
         占位变第一段文字,后续 delta 增量 append
t=DONE   face: TALKING → HAPPY_BLINK(0.8s)
         之后回 IDLE
失败    face: → SAD(2s)→ IDLE;inline error 显示
```
