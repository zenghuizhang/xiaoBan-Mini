# M5Stack CoreS3 Companion Robot UI v3
- Added Theme support: Adult (minimalist tech, dark/cyan) and Child (lively colors, rounded, bright).
- Theme is controlled via URL parameter `theme=adult` or `theme=child`.
- Added a Theme Toggle button in the BottomBar.
- Updated all components (Face, BottomBar, StatusBar, MenuOverlay) to adapt to the current theme.
