# xiaoBan-Mini 育儿助手 · UX 设计

> V1.0 · 2026-08-15 · 320×240 屏幕 · 语音优先 + 触摸辅助

---

## 一、设计原则

### 1.1 面向孩子（3–6 岁）

| 原则 | 说明 |
|------|------|
| **语音优先** | 不认字，所有交互靠语音 + 表情 + 简单图标 |
| **即时反馈** | 每次回答都有表情+语音反馈，< 3 秒 |
| **正向激励** | 答错不批评，"再想想？"；答对给星星 + 开心表情 |
| **低认知负荷** | 一次只出一道题，屏幕只显示当前题目的关键提示 |
| **防沉迷** | 15 分钟强制休息，1 小时当日锁定 |

### 1.2 面向家长

| 原则 | 说明 |
|------|------|
| **可信** | 育儿回答有出处感，进度报告数据透明 |
| **可控** | 可设置年龄、时长、查看/清除孩子数据 |
| **不打扰孩子** | 家长模式独立入口，不打断孩子游戏 |

## 二、语音交互流程

### 2.1 孩子游戏主流程

```
[唤醒] "你好小智"
    │
    ▼
[身份开场] "我是 AI 小伴，陪你玩思维游戏！今天想玩分类、排序还是找规律？"
    │
    ▼
[选择游戏] 孩子说"分类" / 触摸图标
    │
    ▼
[出题] "请告诉我，哪些是红色的？"  +  屏幕：🔴🔵🟡 图标 + EXPR_CURIOUS
    │
    ▼
[孩子回答] "苹果！"
    │
    ├─ 答对 ──► EXPR_HAPPY + "答对啦！+1 颗星 ⭐" → 下一题
    │
    └─ 答错 ──► EXPR_CUTE + "再想想？红色的东西还有什么？" → 重试
```

### 2.2 家长模式入口

```
方式一：语音 "家长模式" → "请说出口令" → 家长说口令 → 进入
方式二：设置页 → 家长模式
```

### 2.3 语音 + 触摸双通道

- **语音**：自由回答，适合分类/因果等开放题。
- **触摸**：屏幕显示 2–4 个选项图标，孩子点选，适合排序/找规律等结构化题。
- 双通道可切换：孩子不说话时，自动弹出触摸选项。

## 三、思维游戏状态机

```
         ┌──────────┐
         │   IDLE   │  (待机，表情 EXPR_IDLE)
         └────┬─────┘
              │ 唤醒 / 选择游戏
              ▼
         ┌──────────┐
         │ ASKING   │  出题中，EXPR_CURIOUS
         └────┬─────┘
              │ 出题完成
              ▼
         ┌──────────┐
         │ WAITING  │  等待孩子回答，EXPR_LISTENING
         └────┬─────┘
              │ 收到回答
              ▼
         ┌──────────┐
         │ JUDGING  │  判断对错，EXPR_THINKING
         └────┬─────┘
         ┌────┴────┐
         │ 对      │ 错
         ▼         ▼
   ┌──────────┐ ┌──────────┐
   │ FEEDBACK │ │ FEEDBACK │  EXPR_HAPPY / EXPR_CUTE
   │  正确    │ │  鼓励重试 │
   └────┬─────┘ └────┬─────┘
        │            │ 重试 ≤2 次
        │            ▼
        │      ┌──────────┐
        │      │  HINT    │  给提示
        │      └────┬─────┘
        │           │
        └─────┬─────┘
              ▼
         ┌──────────┐
         │  NEXT    │  下一题 / 升级难度
         └────┬─────┘
              │
              ▼
         回到 ASKING
```

**状态说明**：
- **IDLE**：无游戏进行，表情自然呼吸。
- **ASKING**：AI 正在念题，屏幕显示题目图标。
- **WAITING**：等待孩子语音/触摸回答，EXPR_LISTENING。
- **JUDGING**：LLM 判断答案，EXPR_THINKING。
- **FEEDBACK**：给出对错反馈 + 星星，停留 2 秒。
- **HINT**：答错 2 次后给提示，降低难度。

## 六、时长管理 UX

### 6.1 单次 15 分钟提醒

- 连续游戏 15 分钟时：
  1. 语音："玩了 15 分钟啦，眼睛休息一下吧～"
  2. 表情：`EXPR_SLEEPY`
  3. 屏幕：休息页
  4. 行为：暂停游戏，30 秒后可继续（家长可关闭"再玩 5 分钟"选项）

### 6.2 每日 1 小时上限

- 累计游戏 1 小时后：
  1. 语音："今天玩够啦，明天再来找我玩吧！"
  2. 表情：`EXPR_BORED`
  3. 行为：当日锁定游戏，次日 0 点解锁
  4. 家长可在设置页调整上限或临时解锁

### 6.3 家长设置

设置页 → 家长模式 → 时长设置：
- 单次时长：10 / 15 / 20 / 30 分钟
- 每日上限：30 / 45 / 60 / 90 分钟
- 是否允许"再玩 5 分钟"

## 七、家长模式 UX

### 7.1 入口

- **语音**：待机时说"家长模式" → 口令验证 → 进入
- **触摸**：设置页 → 家长模式

### 7.2 口令验证

- 家长首次设置 4 位数字口令（语音或触摸输入）
- 进入家长模式需验证口令
- 防止孩子误进入

### 7.3 三大功能

| 功能 | 交互 |
|------|------|
| **育儿问答** | 语音提问，LLM 回答；可追问 |
| **每日贴士** | 基于孩子年龄推送 1 条发展里程碑 + 家庭活动 |
| **进度报告** | 本周游戏次数、正确率、能力雷达、建议 |

## 八、内容安全 UX

### 8.1 AI 身份透明

- 每次进入孩子模式，开场必说："我是 AI 小伴，陪你玩思维游戏。"
- 不伪装成人类、不做"AI 妈妈/朋友"人设。

### 8.2 内容过滤

- 游戏题库：人工审核 + LLM 生成后过滤。
- LLM 自由问答（家长模式）：经内容安全过滤，不输出暴力/成人/敏感内容。
- 孩子模式不开放自由问答，只在结构化游戏内交互。

### 8.3 数据最小化

- **不存儿童语音**：ASR 结果仅用于判断对错，不持久化。
- **只存结构化结果**：题型、对错、用时、星星数。
- 家长可一键清除所有孩子数据。

## 十、无障碍与容错

| 场景 | 处理 |
|------|------|
| 孩子不说话 | 3 秒后弹出触摸选项 |
| ASR 识别失败 | "没听清，再说一次好吗？"，重试 2 次后给触摸选项 |
| 答错 2 次 | 给提示，降低难度，不让孩子挫败 |
| 网络断开 | "网络好像断了，我们玩不用网的游戏吧" → 切换本地题库 |
| 家长忘记口令 | 长按设置键 5 秒重置（需清除孩子数据） |
