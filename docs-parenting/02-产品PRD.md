# xiaoBan-Mini 育儿助手 · 产品 PRD

> V1.0 · 2026-08-15 · 基于市场报告与方向调研

---

## 一、产品定位

### 1.1 一句话定义

**xiaoBan-Mini 育儿助手**是一个坐在桌面上的 AI 思维训练伙伴——用语音思维游戏培养 3–6 岁孩子的逻辑思维，同时为家长提供育儿知识问答与孩子成长反馈。

### 1.2 核心差异化

> **一个设备，两个用户。**

| | 现有 AI 玩具 | 现有育儿 App | **xiaoBan 育儿助手** |
|---|---|---|---|
| 服务对象 | 只服务孩子 | 只服务家长 | **孩子 + 家长双场景** |
| 孩子端 | 通用对话/儿歌 | 无 | **皮亚杰分级思维游戏** |
| 家长端 | 无 | 文章/问答 | **育儿问答 + 孩子游戏进度反馈** |
| 合规 | 多踩红线 | 合规但孩子不碰 | **教育工具定位 + 未成年人模式** |

### 1.3 目标用户

- **孩子**：3–6 岁，皮亚杰前运算阶段，需训练分类/排序/找规律/因果推理。
- **家长**：25–40 岁，重视早教但焦虑、缺乏系统方法，愿意为"有教育沉淀"的产品付费。

### 1.4 核心价值

1. **孩子**：在游戏中训练逻辑思维，有星星奖励，不沉迷。
2. **家长**：获得科学育儿知识 + 孩子思维发展的可视化反馈。
3. **合规**：教育工具定位，不存儿童语音，时长硬限制。

## 二、功能架构

```
xiaoBan 育儿助手
├── 孩子模式（默认）
│   ├── 思维游戏引擎
│   │   ├── 分类游戏（按颜色/形状/维度分类）
│   │   ├── 排序游戏（大小/多少/规律排序）
│   │   ├── 找规律游戏（ABAB/ABCABC/递增）
│   │   └── 因果推理游戏（因→果、反事实）
│   ├── 星星奖励系统
│   └── 时长管理（15 分钟/次，1 小时/天）
├── 家长模式（语音"家长模式"或设置页进入）
│   ├── 育儿知识问答
│   ├── 每日育儿贴士
│   └── 孩子游戏进度报告
└── 系统层
    ├── 儿童内容安全过滤
    ├── AI 身份透明开场
    ├── 年龄设置（3-4 / 5-6 分级出题）
    └── 数据最小化（不存儿童语音）
```

## 三、功能规格

### 3.1 P0 — MVP 必须有

#### 3.1.1 思维游戏引擎

| 功能 | 描述 | 验收标准 |
|------|------|---------|
| 游戏状态机 | 出题 → 等待回答 → 反馈 → 下一题 | 状态流转正确，无卡死 |
| 分类游戏 | 语音出题"把红色的东西告诉我"，孩子说答案，判断对错 | 支持颜色/形状/类别，答对给星星 |
| 排序游戏 | "从小到大排好队"，孩子依次说出排序 | 支持 3–5 个物体排序 |
| 找规律游戏 | "苹果、香蕉、苹果、香蕉，接下来是什么？" | 支持 ABAB、ABCABC 模式 |
| 语音交互 | 唤醒 → 出题 → 识别孩子回答 → 反馈 | 端到端延迟 < 3 秒 |
| 星星奖励 | 答对 +1 星，累计解锁成就 | 星星数持久化到 NVS |

#### 3.1.2 时长管理（合规硬要求）

| 功能 | 描述 | 验收标准 |
|------|------|---------|
| 单次 15 分钟提醒 | 连续游戏 15 分钟后语音提醒"休息一下" | 到时自动暂停游戏 |
| 每日 1 小时上限 | 累计游戏 1 小时后当日锁定 | 次日 0 点解锁 |
| 家长可配置 | 家长可调整单次/每日时长 | 设置页可改，持久化 |

#### 3.1.3 儿童内容安全

| 功能 | 描述 | 验收标准 |
|------|------|---------|
| 内容过滤 | 游戏内容 + LLM 回答经安全过滤 | 不出现暴力/成人/敏感内容 |
| AI 身份透明 | 每次开场"我是 AI 小伴，陪你玩思维游戏" | 每次进入孩子模式必说 |
| 不存儿童语音 | ASR 结果不持久化，只存游戏结构化结果 | NVS 中无音频/原始文本 |

#### 3.1.4 家长模式

| 功能 | 描述 | 验收标准 |
|------|------|---------|
| 育儿问答 | 家长提问，LLM 基于育儿知识库回答 | 回答科学、有出处感 |
| 每日贴士 | 开机/家长模式时推送 1 条年龄适配贴士 | 内容随孩子年龄变化 |
| 进度报告 | 孩子玩了哪些游戏、正确率、哪类能力强弱 | 结构化展示，不存语音 |

### 3.2 P1 — 增强体验

| 功能 | 描述 |
|------|------|
| 因果推理游戏 | "为什么杯子碎了？"多步因果 + 反事实 |
| 成就系统 | 连续答对、累计星星解锁徽章 |
| 触摸选择 | 除语音外，支持屏幕触摸选答案（降低 ASR 依赖） |
| 家长报告周报 | 每周生成孩子思维发展小结 |

### 3.3 P2 — 远期扩展

| 功能 | 描述 |
|------|------|
| 多孩子档案 | 支持多个孩子的年龄/进度独立 |
| 题库开放 | 家长/开发者可自定义题目 |
| 幼儿园 B 端 | 班级思维训练 + 教师报告 |

## 四、用户流程

### 4.1 孩子游戏流程

```
唤醒"你好小智"
    ↓
AI 身份开场："我是 AI 小伴，陪你玩思维游戏"
    ↓
选择游戏（语音/触摸）：分类 / 排序 / 找规律
    ↓
出题（语音 + 屏幕表情/图标提示）
    ↓
孩子回答（语音 / 触摸）
    ↓
判断对错
    ├─ 对 → 开心表情 + "答对啦！+1 星" → 下一题
    └─ 错 → 鼓励表情 + "再想想？" → 重试或提示
    ↓
15 分钟提醒 → 休息
    ↓
1 小时上限 → 当日锁定
```

### 4.2 家长模式流程

```
语音"家长模式" / 设置页进入
    ↓
家长身份确认（可选：简单口令）
    ↓
选择：育儿问答 / 每日贴士 / 进度报告
    ↓
问答：LLM 基于育儿知识库回答
    ↓
进度：展示孩子本周游戏次数、正确率、能力雷达
```

## 五、思维游戏设计（皮亚杰分级）

### 5.1 分级出题

| 能力 | 3–4 岁 | 5–6 岁 |
|------|--------|--------|
| 分类 | 单维度（颜色/形状） | 双维度（颜色+大小） |
| 排序 | 3 个物体 | 5 个物体 + 规律排序 |
| 找规律 | ABAB | ABCABC + 递增 |
| 因果 | 单因单果 | 多步因果 + 反事实 |

### 5.2 题目生成

- **题库种子**：每类游戏 20 道人工审核题（P0）。
- **LLM 扩展**：用 system prompt 约束 LLM 按皮亚杰分级生成新题，经内容安全过滤后入库。
- **难度自适应**：连续答对 3 题升一级，连续答错 2 题降一级。

## 六、合规设计

| 合规项 | 实现 |
|--------|------|
| 教育工具定位 | 产品名/人设/宣传均为"思维训练"，不出现"陪伴/情感依赖" |
| 未成年人模式 | 默认开启，内容安全过滤 + 时长限制 |
| AI 身份透明 | 开场明示"我是 AI 小伴" |
| 数据最小化 | 不存儿童语音，只存结构化游戏结果（题型/对错/用时） |
| 时长限制 | 15 分钟/次提醒，1 小时/天锁定 |
| 家长可控 | 家长可设置年龄、时长、查看/清除数据 |

## 七、MVP 三阶段规划

| 阶段 | 周期 | 交付 | 验证目标 |
|------|------|------|---------|
| **Phase 1** | 1–2 周 | 育儿助手人格 prompt + 内容安全过滤 + 时长管理 + 年龄设置 | 合规底座就绪，能跑通"AI 身份开场 + 时长限制" |
| **Phase 2** | 2–3 周 | 分类/排序/找规律 3 个思维游戏 + 状态机 + 星星奖励 | 孩子能玩、能获得反馈，验证"好玩 + 有教育沉淀" |
| **Phase 3** | 1–2 周 | 育儿知识库 + 家长问答 + 每日贴士 + 进度报告 | 家长端闭环，验证"家长愿意付费" |

---

## 八、非功能需求

| 项 | 要求 |
|----|------|
| 响应延迟 | 唤醒 → 出题 < 2s；孩子回答 → 反馈 < 3s |
| 时长精度 | 15 分钟/1 小时限制误差 < 10s |
| 数据持久化 | 星星数、游戏记录、家长设置存 NVS，断电不丢 |
| 内容安全 | 游戏题 + LLM 回答 100% 经过滤 |
| 隐私 | 不存儿童语音原始数据 |
| 稳定性 | 连续运行 8 小时无崩溃 |

## 九、与现有基座的关系

xiaoBan 现有基座（唤醒+ASR+LLM+TTS+表情+人格+技能）已编译通过，育儿助手在此之上叠加：

- **复用**：语音链路、表情系统、LLM 对话、NVS 持久化、设置页。
- **新增**：思维游戏引擎、星星奖励、时长管理、儿童内容过滤、育儿知识库、家长模式。
- **不改动**：语音链路底层（或按方向调研建议，未来 fork xiaozhi 替换）。
