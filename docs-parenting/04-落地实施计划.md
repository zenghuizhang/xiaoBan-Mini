# xiaoBan-Mini 育儿助手 · 落地实施计划

> V1.0 · 2026-08-15 · 基于 PRD 三阶段规划

---

## 总览

| 阶段 | 周期 | 核心交付 | 验证目标 |
|------|------|---------|---------|
| **Phase 1** | 1–2 周 | 育儿助手人格 + 内容安全过滤 + 时长管理 + 年龄设置 | 合规底座就绪 |
| **Phase 2** | 2–3 周 | 分类/排序/找规律 3 个思维游戏 + 状态机 + 星星奖励 | 孩子能玩、有反馈 |
| **Phase 3** | 1–2 周 | 育儿知识库 + 家长问答 + 每日贴士 + 进度报告 | 家长端闭环 |

## Phase 1：合规底座

### 1.1 育儿助手人格（system prompt）

**任务**：新增"育儿助手"人格，system prompt 约束：
- AI 身份："我是 AI 小伴，陪 3-6 岁小朋友玩思维游戏"
- 不做情感陪伴、不诱导依赖
- 回答仅限思维游戏 + 育儿知识
- 孩子模式：只出游戏题，不开放自由聊天
- 家长模式：回答育儿问题，给出科学建议

**文件**：`main/ui/persona.*`（或现有人格系统）
**改动**：新增 `PERSONA_PARENTING` 人格，system prompt 写入。

### 1.2 儿童内容安全过滤

**任务**：
- 游戏题 + LLM 回答经关键词过滤 + LLM 二次审核
- 黑名单：暴力、成人、敏感、宗教、政治
- 孩子模式：只允许结构化游戏交互，不开放自由问答

**文件**：新建 `main/productivity/content_safety.{h,cpp}`
**接口**：`content_safety_filter(text) → bool`（是否安全）

### 1.3 时长管理

**任务**：
- 单次游戏 15 分钟提醒（可配 10/15/20/30）
- 每日累计 1 小时上限（可配 30/45/60/90）
- NVS 持久化：今日累计时长、最后日期
- 到时语音提醒 + 表情 + 锁定

**文件**：新建 `main/productivity/play_time.{h,cpp}`
**接口**：
- `play_time_init()`
- `play_time_start()` / `play_time_stop()`
- `play_time_remaining_session()` / `play_time_remaining_daily()`
- `play_time_is_locked()`
- `play_time_set_limits(session_min, daily_min)`

### 1.4 年龄设置

**任务**：
- 设置页新增"孩子年龄"：3-4 岁 / 5-6 岁
- NVS 持久化
- 影响游戏出题难度（Phase 2 使用）

**文件**：`main/ui/page_settings.cpp` + `settings_store`

### 1.5 Phase 1 验收

- [ ] 唤醒后 AI 自报身份"我是 AI 小伴"
- [ ] 连续游戏 15 分钟弹出休息提醒
- [ ] 累计 1 小时当日锁定
- [ ] 设置页可改年龄、时长
- [ ] 内容过滤拦截违规词

## Phase 2：思维游戏引擎

### 2.1 游戏状态机

**任务**：实现 `GAME_IDLE → ASKING → WAITING → JUDGING → FEEDBACK → NEXT` 状态机。

**文件**：新建 `main/productivity/game_engine.{h,cpp}`

### 2.2 三个核心游戏

| 游戏 | 3-4 岁 | 5-6 岁 | 出题方式 |
|------|--------|--------|---------|
| 分类 | 单维度（颜色/形状） | 双维度（颜色+大小） | "哪些是红色的？" |
| 排序 | 3 个物体 | 5 个物体 | "从小到大排好队" |
| 找规律 | ABAB | ABCABC | "接下来是什么？" |

**文件**：`main/productivity/games/classify.cpp`、`sort.cpp`、`pattern.cpp`

### 2.3 星星奖励

**任务**：答对 +1 星，NVS 持久化，累计解锁成就。

**文件**：`main/productivity/star_reward.{h,cpp}`

### 2.4 语音 + 触摸双通道

**任务**：
- 语音回答走 ASR → 判断
- 3 秒无语音 → 弹出触摸选项
- 触摸选择直接判断

### 2.5 Phase 2 验收

- [ ] 能玩分类/排序/找规律三个游戏
- [ ] 答对给星星，答错给提示
- [ ] 语音 + 触摸双通道
- [ ] 难度随年龄分级

## Phase 3：家长端

### 3.1 育儿知识库

**任务**：内置 100+ 条育儿知识（3-6 岁发展里程碑、常见问题、家庭活动）。

**文件**：`main/productivity/parenting_knowledge.{h,cpp}`

### 3.2 家长问答

**任务**：家长模式下语音提问，LLM 基于育儿知识库回答。

### 3.3 每日育儿贴士

**任务**：开机/进入家长模式推送 1 条年龄适配贴士。

### 3.4 进度报告

**任务**：统计孩子本周游戏次数、正确率、能力雷达图。

### 3.5 Phase 3 验收

- [ ] 家长模式可问答育儿问题
- [ ] 每日推送年龄适配贴士
- [ ] 进度报告展示游戏数据
- [ ] 家长可设置/清除孩子数据

## 与现有代码的复用

| 现有模块 | 复用方式 |
|---------|---------|
| 语音链路（唤醒+ASR+LLM+TTS） | 直接复用，游戏交互走同一链路 |
| 表情系统（26 种 EXPR_*） | 映射到游戏状态 |
| 人格系统（6 人格） | 新增"育儿助手"人格 |
| 设置页 | 新增年龄/时长/家长口令设置 |
| NVS 持久化 | 星星、时长、年龄、游戏记录 |
| dialog_bubble | 游戏反馈、休息提醒 |

## 风险与缓解

| 风险 | 缓解 |
|------|------|
| 儿童 ASR 准确率低 | 游戏用短词（颜色/数字），支持触摸选择 |
| 内容安全漏检 | 关键词过滤 + LLM 审核双保险 |
| 题库不足 | LLM 生成 + 人工审核，先 20 道/类 |
| 孩子沉迷 | 15 分钟/1 小时硬限制 |
