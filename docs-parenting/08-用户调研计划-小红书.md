# xiaoBan 用户调研计划（小红书优先，低成本验证付费意愿）

> 调研规范 · 2026-08-16 · 关联定位 V3（〔07-产品定位V3-内容订阅生意〕）
> 目标：在投入硬件前，用最便宜的方式验证 **"3-6 岁家长会不会为『思维训练 + 家长育儿认知』付 ¥89/月 订阅"**，而非只买一次硬件。

---

## 一、为什么先在小红书调研

- 母婴/育儿生态是 3-6 岁家长（尤其妈妈）**决策链最短**的场，也是我们市场报告里的第一获客渠道。
- 验证付费意愿的成本：**小红书 ≈ 免费~几百元；造一台无屏终端再来验证 ≈ 万元级 + 数月**。差一个量级。

### 前提（小红书数据的两条局限，务必记住）
1. **用户偏斜**：偏一二线、女性、"精致育儿"。低线城市家长付费弹性更低 → 站内信号只当**方向性**，不能外推成全国样本。
2. **高赞 ≠ 会付费**：收藏≠下单。所以**最终必须落到付费/下单意愿**，不能只看赞藏。

---

## 二、分阶段打法（由便宜到贵、由被动到主动）

### 阶段 0 · 先听，不发声（几乎零成本，最先做）
- 站内搜关键词：`3岁 思维训练`、`护眼 学习机`、`点读笔 吃灰`、`早教机 值不值`、`斑马思维机`、`逻辑狗`、`优彼`
- 重点读**高赞笔记的评论区**——家长真实吐槽：买回家吃灰的、后悔的、真正纠结的点（护眼？价格？孩子不爱玩？）
- 看竞品**晒单 + 差评**（斑马/逻辑狗/小彼恩）：差评是金矿，每条都是需求裂缝
- 用**第三方工具（千瓜/灰豚/布布）**看关键词热度、笔记量、互动趋势——小红书不公开搜索指数，想拿量化必须靠工具

### 阶段 1 · 内容种草测需求（发几条笔记做"需求探针"）
- 发**不卖货**的育儿选题笔记，例：
  - "3 岁要不要练思维训练？练什么、怎么练？"
  - "无屏不伤眼，怎么在家练孩子思维？"
  - "点读笔和思维机到底哪个不是智商税？"
- 量化指标：**收藏 / 评论追问 / 私信咨询**（收藏+追问 = 真需求），不只关注赞
- 评论区与私信里自然出现的"要是能……就好 / 有没有……"就是产品机会点

### 阶段 2 · KOC / 母婴买手访谈（花点钱，拿一手）
- 私信 10-20 个 3-6 岁育儿博主或母婴买手，**付费 30 分钟 1v1 访谈**或送样评测
- 他们天天接触真实家长，最清楚"什么被买单、什么吃灰"
- 顺带拿**愿不愿意带货/带订阅**的意愿 = 渠道可行性信号

### 阶段 3 · 问卷 / 投票落到付费意愿（核心门槛）
- 用小红书"投票"功能或站内问卷，直接问那条分辨题：
  - **"一台无屏思维小教练，你会选：① ¥400 一次性买硬件 ② 每月 ¥89 订阅（含思维课+育儿报告）③ 都不想"**
  - 细分追加：**"现在家里有 斑马/逻辑狗/点读笔 吗？吃灰了吗？"**
- 拿到真实比例的付费结构 = 前面验证门的第一个实证数据

### 阶段 4 · 真实下单测试（最硬，最后做）
- 有可售的最小内容（电子题库/育儿报告/小程序会员）后，**挂链接 / 蒲公英投流看真实转化率**
- 愿意付费的人数 = 终极答案；这一步过，才谈得上下一步做终端还是换层

---

## 三、一周落地建议

> **本周做阶段 0 + 阶段 1**：零成本先在评论区"偷听"真实痛点和吃灰抱怨，同时发 5–8 条育儿选题笔记测需求热度。一周后看数据，再决定要不要进阶段 2/3。

---

## 四、输出与决策

- 产出一份「家长付费意愿」证据：**订阅 vs 硬件**的比例 + 吃灰/替代情况 + 需求痛点清单
- 决策门：
  - 家长明显倾向"订阅" → 深耕内容订阅生意，再造无屏终端
  - 家长只愿买硬件 / 平台无转化 → **不造硬件，定位或换层止损**

---

## 五、8 条育儿选题笔记（阶段 1 需求探针，2026-08-16）

> 用途：阶段 1 的天平种子。**不卖货**，靠「收藏 / 评论追问 / 私信」测需求。每条都对应一个待验证假设并标注"看什么信号"。发 5–8 条，一周后读数据（见第四节决策门）。

### 📝 1. 无屏/护眼焦虑探针
**标题**：为了娃的眼睛，我把家里屏幕全收了……结果太意外了
**正文**：3 岁体检居然查出 50 度了，医生让孩子少碰屏。可一收屏娃就闹，饭都不好好吃😭。家里 iPad、电视都想处理掉。大家都是怎么跟"屏幕"打仗的？有没有什么能陪娃玩又不废眼睛的东西？
**钩子**：评论区接龙 "你家每天让娃看多久屏？"
**命中**：护眼/近视焦虑是不是 3-6 家长的真痛点
**看信号**：收藏高 + 大量"同样纠结"评论 → 无屏护眼成立；若都在说"我家管得住，没这焦虑" → 痛点不普适

### 📝 2. 思维训练必要性探针
**标题**：3 岁到底要不要"练思维"？不练会不会落后？
**正文**：刷到好多 3 岁娃在玩思维训练，说能从分类、找规律里练逻辑。我娃只会瞎玩，我好慌。可又怕交了智商税……有没有过来人告诉我：这种"思维训练"是真有必要，还是贩卖焦虑？
**钩子**：投票 "你觉得 3 岁思维训练：A 很有必要 B 纯智商税 C 顺其自然"
**命中**：家长对"思维训练"的付费认知与焦虑强弱
**看信号**：大量"我也在纠结/已经买了斑马逻辑狗"评论 → 付费心智在；若主流"顺其自然/自己教" → 软需求坐实

### 📝 3. 吃灰/弃用探针（最关键一条）
**标题**：买过的早教机、点读笔，到底有没有吃灰？
**正文**：家里点读笔、思维机、故事机一堆，当初都吹得天花乱坠，现在……有的吃灰一年了😅。这东西到底是"娃不爱"还是"我不会用"？你家那个现在还在用吗？值回票价的举个手🙋
**钩子**：都在评论区交底牌 "用 / 吃灰"
**命中**：直接验证 "AI 玩具/思维机三天热度" 是否真是行业死坑
**看信号**：若评论区大面积"吃灰/后悔" → 必须做订阅续费模型才可能破；这是阶段 0/1 最该看的一条

### 📝 4. 解放家长探针
**标题**：一个人带娃的崩溃瞬间：真的没人能替我跟娃玩会儿吗
**正文**：忙得脚不沾地的时候，真的希望有个什么能"自动出题、自己考娃、娃答对还有奖励"，不用我盯、又不伤眼、还不会让娃吵着看动画。是我要求太高，还是这种东西真该存在？在线等一个"既能解放我、又不坑娃"的答案。
**钩子**：评论区接龙 "你需要一个会自己带娃玩的家伙吗？"
**命中**：无屏思维小教练"解放家长"卖点的强度
**看信号**：大量共鸣"太需要了" + 私信问链接 → 卖点成立；若"我还是自己陪吧" → 需求软

### 📝 5. 家长育儿认知探针
**标题**：娃老打人、不分享，到底该不该管？当妈三年我根本不会
**正文**：3 岁娃一言不合就动手、玩具死活不分享，网上专家说啥的都有，越看越懵😵。身边也没个靠谱的人问。你们这些"过来人"都去哪儿学育儿？会不会为"靠谱的育儿答疑"花钱？
**钩子**：投票 "你为育儿知识掏过钱吗：A 买过课/书 B 白嫖博主 C 从不"
**命中**：家长端"育儿问答/认知提升"到底有没有真实付费意愿
**看信号**：若多数"白嫖就好" → 家长端难单独变现，只能当附赠；若有人"愿意为靠谱答疑付费" → 家长端可成付费主线

### 📝 6. 无屏 vs 带屏选型探针
**标题**：无屏思维机和带屏学习机，你会给孩子选哪个？
**正文**：一个说不伤眼但内容看着"简陋"，一个啥都能学但就是费眼睛。我妈说"娃这么小少看屏"，我老公说"买就买全能的"。我直接选择困难。你会怎么选？用过哪个的来卸卸货🙏
**钩子**：投票 "A 无屏护眼 > B 全能带屏 > C 都不买"
**命中**：我们最关键差异化"无屏"在同品类里是否占优
**看信号**：若"无屏护眼"明显压过"全能带屏" → 护眼是家长首选逻辑；若大家狂投"全都能" → 无屏是少数派，定位要重新掂量

### 📝 7. 免费替代压力探针
**标题**：不花钱，能不能自己在家把娃的思维鸡出来？
**正文**：总有人说"思维启蒙根本不用买，陪娃玩、看绘本、搭积木就行"。我试了，发现我不会教、没时间、还不系统😮‍💨。你们是真能自己带，还是也得靠工具？"自己教"和"花钱买"，你们站哪边？
**钩子**：投票 "A 我能自己教 B 必须靠产品"
**命中**：免费替代（绘本/陪玩/免费 AI）的挤压到底多强
**看信号**：若主流"自己教就行" → 付费产品空间很小（危险信号）；若大量"没时间/不会教/要系统" → 产品有救

### 📝 8. 付费愿望/结构探针
**标题**：如果真有这么个东西……你会买单吗（好奇
**正文**：假如有个家伙：不伤眼 + 会自己出题考娃 + 记得娃每次进步 + 还给爸妈育儿建议。你最想要哪种？纯好奇，评论区告诉我⏬
**钩子**：投票 "A 一次性买断几百块 B 每月 ¥89 订阅含内容 C 都不想"
**命中**：直接摸 **订阅 vs 硬件** 的付费结构（阶段 3 的省心预告版）
**看信号**：这是最接近"会不会为 ¥89/月 付费"的一手数据；若多数选 A/怕订阅 → 内容订阅模型存疑，需转平价买断或换层

### 📌 怎么读结果（一周后）
- **收藏高** = 痛点共鸣/想存 → 需求真实
- **评论追问 / 私信问链接** = 意向高 → 有强需求（比收藏更值钱）
- **#3 吃灰** 单测的是我们最担心的行业死坑，重点看它
