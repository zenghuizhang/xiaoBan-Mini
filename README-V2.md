# 小伴 Mini V2.0 - 桌面萌宠·情绪搭子

> 圆滚滚，才治愈

---

## 项目简介

小伴 Mini 是一个坐在桌面上的「情绪搭子」——它不是助手，不需要你命令它；它只是一个安静的小陪伴，会用小动作给你情绪反馈。

- **摸它**：它会歪头、开心、点头
- **说话**：它会看着你、跟着节奏轻轻点头
- **不理它**：它会低头、打哈欠、发呆
- **天黑**：它会自动睡觉；天亮了，它会自动醒来

## 设计原则

1. **如无必要，勿增实体** —— 能不用的部件就不用
2. **慢即是快** —— 动作慢一点，更治愈
3. **少即是多** —— 表情不用多，几个核心的就够
4. **被动而非主动** —— 它不主动打扰你，只在你互动时反应
