# 小伴 Mini V2.0 - M5Stack CoreS3 验证方案

> 快速验证交互逻辑，不用先焊硬件

---

## 一、为什么用 M5Stack CoreS3？

| 硬件 | CoreS3 自带 | 对应小伴的功能 |
|-----|------------|--------------|
| 屏幕 | 2.0寸 LCD（320x240） | 显示眼睛表情 |
| 触摸 | 电容触摸屏幕 | 模拟"摸头顶" |
| IMU | MPU6886 6轴 | 检测摇晃 |
| 麦克风 | MSM261S4030 | 声音感知 |
| 电源 | 自带锂电池 | 不用接线 |
| 按键 | 3个物理按键 | 快速切换状态 |
| GPIO | 扩展引脚 | 外接舵机（可选） |

---

## 二、验证阶段划分

### Phase A：纯软件交互（0-1天）
**目标**：验证交互逻辑、表情、状态机，不用任何外接硬件

| 功能 | 实现方式 |
|-----|---------|
| 摸头顶 | 触摸屏幕上半部分 |
| 声音感知 | 用 CoreS3 麦克风 + 简单能量检测 |
| 摇晃 | 用 CoreS3 IMU |
| 眼睛表情 | 用 CoreS3 LCD 显示 |
| 动作 | 用屏幕上的"虚拟舵机"模拟（或者文字提示） |

### Phase B：外接舵机（1-2天）
**目标**：验证真实舵机动

| 功能 | 实现方式 |
|-----|---------|
| 点头 | GPIO 接 SG90 舵机1 |
| 歪头 | GPIO 接 SG90 舵机2 |

## 三、CoreS3 上的交互 UI 设计

### 屏幕布局（320x240）

```
┌─────────────────────────────────┐
│  （上半部分：摸这里唤醒）       │ ← 触摸区域：摸这里=摸头顶
│                                 │
│         ●        ●              │ ← 眼睛
│                                 │
│             ~                   │ ← 嘴巴
│                                 │
│  （下半部分：状态提示）          │
│  [状态：清醒]                   │
│  [最后活动：10秒前]             │
└─────────────────────────────────┘
```

### UI 元素说明

| 区域 | 位置 | 功能 |
|-----|------|------|
| **触摸区** | 上半部分（y < 120） | 摸这里 = 摸小伴头顶 |
| **眼睛区** | 居中（y=80-140） | 显示眼睛表情 |
| **嘴巴区** | 居中偏下（y=160） | 显示嘴巴 |
| **状态栏** | 底部（y=200-240） | 显示当前状态、最后活动时间 |
| **按钮提示** | 左下角 | 按钮A：切换表情；按钮B：模拟声音；按钮C：重置 |

---

## 四、CoreS3 按键映射

| CoreS3 按键 | 功能 |
|------------|------|
| **按钮A（左）** | 手动切换表情（中立→开心→好奇→困） |
| **按钮B（中）** | 模拟"有声音"（触发好奇反应） |
| **按钮C（右）** | 重置状态（回到清醒态） |

---

## 五、虚拟舵机（Phase A 用）

在 Phase A 没有真实舵机时，用屏幕上的动画模拟动作：

| 真实动作 | 屏幕模拟方式 |
|---------|------------|
| 点头 | 眼睛上下移动（幅度小） |
| 歪头 | 整个脸左右倾斜 |
| 开心时 | 眼睛弯成月牙 + 脸颊加红晕 |
| 好奇时 | 眼睛睁大 + 加个问号 |
| 困时 | 眼睛半睁 + 加 Zzz |

---

## 六、验证 checklist

### Phase A 验收
- [ ] 摸屏幕上半部分 → 眼睛变开心 + 虚拟点头
- [ ] 按按钮B（模拟声音）→ 眼睛变好奇 + 虚拟点头
- [ ] 30秒无操作 → 眼睛变困 + 虚拟低头
- [ ] 摇晃 CoreS3 → 眼睛变惊讶
- [ ] 按按钮A → 手动切换表情
- [ ] 状态栏实时显示当前状态
- [ ] 状态机正常流转（清醒→兴奋→清醒→睡眠）

### Phase B 验收
- [ ] 外接2个舵机，能正常控制
- [ ] 摸屏幕 → 舵机歪头 + 点头
- [ ] 按按钮B → 舵机轻轻点头
- [ ] 30秒无操作 → 舵机低头
- [ ] 动作流畅，不卡顿
