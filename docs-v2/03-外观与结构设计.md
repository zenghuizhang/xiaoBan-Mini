## 一、外观方案："小蛋黄"

### 设计理念
- **整体造型**：一个扁扁的椭圆形，像个剥了壳的水煮蛋
- **风格**：极简、圆润、无棱角
- **配色**：奶白色（主体）+ 暖黄色（眼睛）

### 尺寸参数
| 项 | 尺寸 |
|---|------|
| 整体高度 | 约 7cm |
| 最大直径 | 约 9cm |
| 底座直径 | 约 6cm |
| 重量 | 约 150g |

### 三视图（文字描述）

```

## 二、结构组成

### 分层设计
```
┌─────────────────────────┐
│    上盖（头部）          │ ← 内置 OLED 屏幕
├─────────────────────────┤
│    中间层（身体）        │ ← 内置 ESP32-C3 + 电池
├─────────────────────────┤
│    舵机组（动作层）      │ ← 2个 SG90 舵机
├─────────────────────────┤
│    底座（固定）          │ ← 配重，防止倒
└─────────────────────────┘
```

### 部件清单（3D打印）
| 部件 | 数量 | 说明 |
|------|------|------|
| 上盖（头部） | 1 | 椭圆顶，正面开 OLED 窗口 |
| 中壳（身体） | 1 | 圆柱，容纳主控和电池 |
| 舵机架 | 1 | 固定 2 个舵机 |
| 底座 | 1 | 加重，保持稳定 |
| 头顶触摸盖 | 1 | 软一点的材质（或者用 PLA，里面贴 TTP223） |

### 关节设计
- **点头关节**：舵机1 驱动整个上半部分（头部+身体）前后摆动
- **歪头关节**：舵机2 驱动整个上半部分左右倾斜
- **范围**：
  - 点头：±20°（从中间位置）
  - 歪头：±15°（从中间位置）

## 三、表情设计（OLED 屏幕）

### 屏幕用法
- **位置**：上盖正面，居中
- **显示内容**：只显示一对眼睛 + 偶尔一个嘴巴
- **不显示**：时间、文字、复杂图像（太乱）

### 基础表情库

| 表情名 | 眼睛 | 嘴巴 | 触发场景 |
|-------|------|------|---------|
| **中立** | ○ ○ | — | 正常状态 |
| **开心** | ^ ^ | ~ | 被摸了 |
| **好奇** | ○ ○ | o | 听到声音 |
| **困** | - - | （不显示） | 长时间没互动 |
| **惊讶** | ○ ○ | O | 被摇晃 |
| **眨眼** | （左闭右睁→右闭左睁→都睁） | — | 随机，或者过渡表情 |

### 表情动画

#### 开心动画（被摸时）
```
帧1：中立（○ ○ —）
帧2：眼睛慢慢变弯（^ ^）
帧3：嘴巴出现（~）
帧4：保持 1 秒
帧5：慢慢回到中立
```

#### 困动画（发呆时）
```
帧1：中立
帧2：眼睛慢慢变小（- -）
帧3：偶尔眨眼（眼睛全闭 0.5 秒）
帧4：保持，直到被唤醒
```

## 四、动作设计

### 基础动作

| 动作名 | 描述 | 触发场景 |
|-------|------|---------|
| **点头** | 慢慢低头 → 慢慢抬头 | 回应触摸、回应声音 |
| **歪头** | 向左歪 → 回正 → 向右歪 → 回正 | 好奇、开心 |
| **抬头** | 从低头位置慢慢回到中立 | 被唤醒 |
| **低头** | 从中立位置慢慢低头 | 进入发呆模式 |

### 组合动作

#### 被摸时的反应
```
1. 歪头（向左 15°）
2. 同时眼睛变开心（^ ^）
3. 慢慢点头 2 次
4. 回正
5. 保持开心表情 1 秒
6. 慢慢回到中立
```

#### 听到声音时的反应
```
1. 抬头（如果在低头）
2. 眼睛变好奇（○ ○）
3. 跟着声音节奏轻轻点头（幅度很小）
4. 声音停后 2 秒，回到中立
```

## 五、内部布局

```

    ┌─────────────────┐

             │

    ┌─────────────────┐
    │  [配重块]        │ ← 增加稳定性
    └─────────────────┘

## 六、3D打印建议

### 打印参数
| 参数 | 值 |
|------|-----|
| 材料 | PLA（推荐，便宜好打） |
| 层高 | 0.2mm |
| 填充 | 20% |
| 外壳数量 | 3 |
| 支撑 | 不需要（设计时已考虑） |

### 组装提示
1. **先装舵机**：把 2 个舵机先装到舵机架，调到 90° 中位再固定
2. **再装屏幕**：OLED 用双面胶粘在上盖内侧，对齐窗口
3. **最后接线**：舵机线、屏幕线从中间层穿到底座
4. **配重**：底座可以放几颗 M3 螺丝当配重，防止倒
