# 小伴 Mini V2.0 - 产品定位与PRD

> 桌面萌宠·情绪搭子

---

## 一、产品定位

### 核心定义
**小伴 Mini** 是一个坐在桌面上的「情绪搭子」——它不是助手，不需要你命令它；它只是一个安静的小陪伴，会用小动作给你情绪反馈。

### 目标用户
- **主要**：桌面工作者（程序员、设计师、学生等）
- **次要**：喜欢萌物的任何人

### 核心价值
1. **非侵入式陪伴**：不吵你，只是默默在旁边
2. **情绪反馈**：你说话时它会看着你点头，你摸它时它会开心
3. **治愈感**：圆滚滚的造型 + 慢半拍的动作，看着就解压

---

## 二、功能规格（PRD）

### P0 - 最小可行产品（必须有）
| 功能 | 描述 | 验收标准 |
|-----|------|---------|
| 触摸唤醒 | 摸头顶 → 歪头 + 开心眼睛 | 每次触摸都有反应，延迟<500ms |
| 基础表情 | 开心、好奇、困三种表情 | OLED 清晰显示 |
| 基础动作 | 点头、歪头 | 2个舵机动作流畅，不卡顿 |
| 发呆模式 | 30秒无操作 → 慢慢低头 + 眼睛半睁 | 自动进入，触摸立即唤醒 |
| 睡眠模式 | 天黑 → 闭眼 + 低头 | 光敏控制，天亮自动醒来 |

### P1 - 增强体验（应该有）
| 功能 | 描述 |
|-----|------|
| 声音感知 | 你说话时 → 抬头看着你 + 跟着节奏轻轻点头 |
| 小动作库 | 偶尔打哈欠、偶尔左右看、偶尔快速眨眼 |
| 简单情绪记忆 | 摸多了 → 反应更"嗨"一点 |

### P2 - 可选扩展（有了更好）
| 功能 | 描述 |
|-----|------|
| 摇晃反馈 | 摇晃它 → 眼睛睁大 + 左右快速看 |
| 简单音效 | 开心时"滴"一声，困时"呼"一声 |

---

## 三、非功能需求

| 项 | 要求 |
|---|------|
| 响应时间 | 触摸到动作 < 500ms |
| 续航 | 500mAh 电池 > 8小时 |
| 噪音 | 舵机动作安静，不打扰工作 |
| 成本 | BOM < ¥80 |
| 尺寸 | 直径 ≤ 10cm，高度 ≤ 8cm |

## 四、用户故事

### 故事1：程序员的日常
> 小王在写代码，遇到bug挠头，随手摸了摸旁边的小伴。小伴歪了歪头，眼睛弯成月牙，慢慢点了点头。小王感觉被安慰了一点，继续写代码。

### 故事2：会议室的陪伴
> 小李开远程会议，有点紧张。小伴在旁边静静地坐着，偶尔看他一眼，偶尔点一下头。小李觉得没那么孤单了。

### 故事3：深夜的陪伴
> 小张在赶作业，很晚了。小伴眼睛半睁着，偶尔打个哈欠。小张感觉不是一个人在熬夜。

## 五、设计原则

1. **如无必要，勿增实体** —— 能不用的部件就不用
2. **慢即是快** —— 动作慢一点，更治愈
3. **少即是多** —— 表情不用多，几个核心的就够
4. **被动而非主动** —— 它不主动打扰你，只在你互动时反应
