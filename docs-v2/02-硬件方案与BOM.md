## 三、引脚分配（ESP32-C3 Mini）

| GPIO | 功能 | 连接 | 说明 |
|------|------|------|------|
| GPIO0 | SCL | OLED SCL | I2C 时钟 |
| GPIO1 | SDA | OLED SDA | I2C 数据 |
| GPIO2 | SERVO1 | 点头舵机 | PWM 输出 |
| GPIO3 | SERVO2 | 歪头舵机 | PWM 输出 |
| GPIO4 | TOUCH | TTP223 OUT | 触摸输入 |
| GPIO5 | LIGHT | 光敏电阻（ADC） | 光线检测 |
| GPIO6 | SOUND | 咪头输出（ADC） | 声音检测 |
| GPIO8 | SCL | MPU6050 SCL | I2C 时钟（复用） |
| GPIO9 | SDA | MPU6050 SDA | I2C 数据（复用） |
| GPIO10 | BUZZER | 蜂鸣器 | 音效输出 |

**注意**：OLED 和 MPU6050 可以共用 I2C 总线（地址不同）。

## 五、关键硬件说明

### 1. 舵机选择
- **型号**：SG90 9G 180°
- **电压**：5V（必须！不能用3.3V）
- **电流**：峰值约 300mA，需要单独供电或用 TP4056 的 5V 输出
- **固定**：先把舵机角度调到 90°（中位）再固定到外壳

### 2. 屏幕选择
- **尺寸**：0.96寸 或 1.3寸（都可以，1.3寸看着更清楚）
- **接口**：必须是 I2C（4根线：VCC/GND/SCL/SDA），不要 SPI
- **驱动**：SSD1306（最常用，资料多）

### 3. 电源方案
- **锂电池**：3.7V 500mAh 带保护板（必须带保护！）
- **充电**：TP4056 模块（带充电指示灯，简单可靠）
- **供电**：
  - ESP32-C3：3.3V（开发板自带稳压）
  - 舵机：5V（从 TP4056 的 5V 输出取）
  - 其他模块：3.3V 或 5V 都可以（看模块规格）
