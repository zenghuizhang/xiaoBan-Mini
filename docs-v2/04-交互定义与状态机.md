# 小伴 Mini V2.0 - 交互定义与状态机

> 被动，而非主动；感知，而非命令

---

## 一、交互方式总览

| 输入方式 | 硬件 | 说明 |
|---------|------|------|
| 触摸 | TTP223 | 摸头顶，最主要的互动方式 |
| 声音 | 咪头（ADC能量检测） | 感知你在说话，不需要识别内容 |
| 光线 | 光敏电阻 | 天黑/天亮，自动睡眠/醒来 |
| 摇晃 | MPU6050（可选） | 摇晃它，给个惊讶反应 |

---

## 二、具体交互定义

### 1. 触摸交互（最常用）

**场景：你摸了摸它的头顶**

| 步骤 | 小伴的反应 | 时长 |
|-----|-----------|------|
| 1 | 歪头（向左 15°） | 0.3s |
| 2 | 眼睛变成开心（^ ^） | 0.2s |
| 3 | 慢慢点头 2 次 | 1.5s |
| 4 | 回正 | 0.3s |
| 5 | 保持开心表情 | 1s |
| 6 | 慢慢回到中立 | 0.5s |

**注意**：如果连续摸（<2秒间隔），它会更"嗨"：
- 第1次摸：正常开心
- 第2次摸：快速点头 + 快速眨眼
- 第3次摸：眼睛更弯 + 头歪得更厉害

---

### 2. 声音交互（陪伴感）

**场景：你对着它说话（不需要命令，随便说什么）**

| 步骤 | 小伴的反应 | 时长 |
|-----|-----------|------|
| 1 | 如果在低头/发呆 → 慢慢抬头 | 0.5s |
| 2 | 眼睛变成好奇（○ ○） | 0.2s |
| 3 | 跟着声音节奏轻轻点头（幅度很小） | 持续到声音停 |
| 4 | 声音停后 2 秒 → 慢慢回到中立 | 0.5s |

**实现方式**：不做语音识别，只做「声音能量检测」——咪头输出的 ADC 值超过阈值就认为"有声音"。

---

### 3. 光线交互（自动睡眠）

**场景：天黑了 / 天亮了**

| 场景 | 小伴的反应 |
|-----|-----------|
| **天黑（光线变暗）** | 1. 慢慢低头<br>2. 眼睛慢慢闭上（- -）<br>3. 进入睡眠模式（舵机断电，省电） |
| **天亮（光线变亮）** | 1. 慢慢抬头<br>2. 眼睛慢慢睁开（○ ○）<br>3. 进入清醒模式 |

**阈值**：可以设置两个阈值，避免频繁切换（滞回）。

---

### 4. 摇晃交互（可选）

**场景：你拿起它晃了晃**

| 步骤 | 小伴的反应 | 时长 |
|-----|-----------|------|
| 1 | 眼睛睁大（○ ○） | 0.1s |
| 2 | 嘴巴变成 O 形 | 0.1s |
| 3 | 快速左右看（歪头左→右→左→右） | 0.8s |
| 4 | 回正，表情慢慢回到中立 | 0.5s |

---

### 5. 发呆/无聊交互（自动）

**场景：30秒没人理它**

| 步骤 | 小伴的反应 | 时长 |
|-----|-----------|------|
| 1 | 慢慢低头 | 1s |
| 2 | 眼睛变成半睁（- -） | 0.5s |
| 3 | 偶尔打个哈欠（眼睛全闭 0.5s，再睁开） | 每 10 秒一次 |
| 4 | 偶尔左右轻轻动一下 | 每 5 秒一次 |

## 三、状态机设计

### 状态定义

```
┌─────────────────────────────────────────────────────────┐
│                                                         │
│   ┌──────────┐       触摸/声音/天亮        ┌──────────┐ │
│   │  睡眠态  │ ──────────────────────────> │  清醒态  │ │
│   │ (Sleep)  │ <──────────────────────────  │ (Awake)  │ │
│   └──────────┘         天黑/3分钟无操作     └────┬─────┘ │
│         ^                                     │       │
│         │                                     │触摸/声音│
│         │                                     │       │
│         │                                     ▼       │
│         │                              ┌──────────┐   │
│         │                              │  兴奋态  │   │
│         └────────────────────────────── │ (Excited)│   │
│                    30秒无操作            └──────────┘   │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

### 状态详情

| 状态 | 屏幕 | 舵机 | 功耗 | 说明 |
|-----|------|------|------|------|
| **睡眠态 (Sleep)** | 全灭 | 断电（保持位置） | 最低 | 天黑或长时间无操作 |
| **清醒态 (Awake)** | 中立表情 | 通电 | 中 | 正常状态 |
| **兴奋态 (Excited)** | 开心/好奇表情 | 做动作 | 较高 | 被触摸或听到声音 |

### 状态跳转规则

| 当前状态 | 事件 | 下一状态 |
|---------|------|---------|
| 睡眠态 | 触摸 / 天亮 / 摇晃 | 清醒态 → 兴奋态 |
| 睡眠态 | （无事件） | 保持睡眠态 |
| 清醒态 | 触摸 / 听到声音 | 兴奋态 |
| 清醒态 | 30秒无操作 | 清醒态 → 进入发呆动画 |
| 清醒态 | 天黑 / 3分钟无操作 | 睡眠态 |
| 兴奋态 | 动作完成 | 清醒态 |
| 兴奋态 | 继续触摸 / 继续有声音 | 保持兴奋态（延长） |
| 兴奋态 | 10秒无事件 | 清醒态 |

## 四、交互细节的"度"

### 反应速度
- **触摸反应**：要快（<500ms），不然会觉得"卡"
- **声音反应**：可以慢一点（100-200ms延迟），显得在"注意听"
- **光线变化**：要慢（>5秒），避免灯一闪就切换

### 动作幅度
- **平时**：动作要小、要慢，显得"慵懒"
- **被摸时**：动作可以稍微大一点，显得"开心"
- **兴奋时**：动作可以快一点，但不要太夸张

### 频率
- **自动小动作**：不要太频繁，5-10秒一次刚好
- **打哈欠**：10-15秒一次，不要太勤
- **连续触摸**：3次以上可以"冷却"一下，不要一直嗨
