# 小伴 Mini V2.0 - 落地计划与进度

> 小步快跑，快速迭代

---

## 一、总体路线图

```
Phase 0: 准备（1天）
  ↓
Phase 1: MVP（2-3天）
  ↓ 能摸、能看、能动
Phase 2: 增强（3-5天）
  ↓ 能听、能睡、能发呆
Phase 3: 优化（可选）
  ↓ 更顺、更萌、更省电
```

---

## 二、Phase 0：准备工作（1天）

### 任务清单
- [ ] 采购硬件（ESP32-C3、2个舵机、OLED、触摸、电池）
- [ ] 搭建开发环境（Arduino IDE + ESP32支持 + 库）
- [ ] 设计3D打印外壳（或找现成的"蛋蛋"模型改）
- [ ] 打印外壳（或淘宝找商家打印）

### 验收标准
- 所有硬件在手
- 开发环境能烧录程序到 ESP32-C3
- 外壳打印完成（或有替代方案）

## 三、Phase 1：最小可行产品（MVP）—— 2-3天

### 目标
**能摸、能看、能动** —— 摸头顶会歪头开心，有基础表情，能点头。

### 任务清单
- [ ] **硬件连接**
  - [ ] ESP32-C3 + OLED（I2C）
  - [ ] ESP32-C3 + 2个舵机（PWM）
  - [ ] ESP32-C3 + TTP223（触摸）
  - [ ] 电源部分（锂电池 + TP4056）

- [ ] **软件模块1：眼睛**
  - [ ] 点亮 OLED
  - [ ] 显示"中立"表情（○ ○ —）
  - [ ] 显示"开心"表情（^ ^ ~）
  - [ ] 显示"困"表情（- -）

- [ ] **软件模块2：舵机**
  - [ ] 舵机1（点头）能从 70° 到 110° 动
  - [ ] 舵机2（歪头）能从 75° 到 105° 动
  - [ ] 实现"点头2次"函数
  - [ ] 实现"歪头"函数

- [ ] **软件模块3：触摸**
  - [ ] 读取 TTP223 状态
  - [ ] 触摸时能触发中断/事件

- [ ] **集成MVP**
  - [ ] 状态机：清醒态/兴奋态
  - [ ] 摸头顶 → 歪头 + 开心表情 + 点头2次
  - [ ] 30秒无操作 → 低头 + 困表情
  - [ ] 再摸 → 立即唤醒

### 验收标准
- [ ] 摸头顶，它会歪头、眼睛变开心、点头2次
- [ ] 30秒不理它，它会低头、眼睛变困
- [ ] 再摸它，它会立即醒来、抬头、表情变中立
- [ ] 连续摸3次，反应会更"嗨"（可选）

## 四、Phase 2：增强体验 —— 3-5天

### 目标
**能听、能睡、能发呆** —— 说话时它会看着你点头，天黑自动睡，天亮自动醒，偶尔做点小动作。

### 任务清单
- [ ] **硬件补充**
  - [ ] 加光敏电阻
  - [ ] 加咪头模块（带放大）
  - [ ] 加电源开关

- [ ] **软件模块4：光线**
  - [ ] 读取光敏电阻 ADC 值
  - [ ] 实现天黑/天亮检测（带滞回）
  - [ ] 天黑 → 自动进入睡眠态
  - [ ] 天亮 → 自动醒来

- [ ] **软件模块5：声音**
  - [ ] 读取咪头 ADC 值
  - [ ] 计算声音能量（简单的滑动平均）
  - [ ] 有声音时 → 抬头 + 好奇表情
  - [ ] 有声音时 → 跟着节奏轻轻点头

- [ ] **软件模块6：小动作库**
  - [ ] 实现"打哈欠"（眼睛闭0.5秒再睁开）
  - [ ] 实现"左右看"（歪头左→右→回正）
  - [ ] 实现"快速眨眼"
  - [ ] 发呆时随机触发小动作

### 验收标准
- [ ] 用手捂住光敏（模拟天黑），10秒后它会闭眼、低头、睡觉
- [ ] 拿开手（模拟天亮），它会慢慢睁眼、抬头、醒来
- [ ] 对着它说话，它会抬头、眼睛好奇、轻轻点头
- [ ] 发呆时，它会偶尔打哈欠、偶尔左右看

## 六、风险与应对

| 风险 | 概率 | 影响 | 应对 |
|-----|------|------|------|
| 硬件缺货 | 中 | 高 | 提前采购，找替代店铺 |
| 3D打印失败 | 中 | 中 | 多打一份，或者用橡皮泥/纸盒先测试 |
| 舵机噪音大 | 低 | 中 | 换更安静的舵机（比如 MG90S），或者加减震 |
| 续航不够 | 低 | 中 | 换更大的电池（1000mAh），或者优化功耗 |
| 开发时间不够 | 中 | 中 | 优先做 MVP，后面再优化 |
